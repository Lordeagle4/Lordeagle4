## About

I design and build software with an emphasis on clear architecture, dependable interfaces, and maintainable systems. My work spans web platforms, APIs, internal tooling, and experiments that explore how programming languages and networked systems work beneath their abstractions.

Through **[AWTechs](https://awtechs.com)**, I work on web platforms, custom infrastructure, and software tailored to real operational needs.

## Focus

- **Backend architecture** — APIs, service boundaries, data flows, and reliable application foundations
- **Developer infrastructure** — tooling and workflows that make software easier to build, ship, and operate
- **Distributed systems** — communication, coordination, failure modes, and resilient design
- **Programming languages** — parsers, interpreters, compilers, and language experiments
- **Networking fundamentals** — protocols and the mechanics behind connected systems
- **Financial infrastructure** — payment and crypto systems, with a focus on their underlying engineering
